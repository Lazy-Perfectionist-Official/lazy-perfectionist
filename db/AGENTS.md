## Database Operations

### Common Commands

## Troubleshooting

### Common Issues
- **Database locked**: Close all connections and restart server
- **Schema mismatch**: Run `npm run db:generate` and `npm run db:push`
- **Migration failures**: Check schema changes and rollback if needed
- **Connection errors**: Verify database file permissions and paths
- **Performance issues**: Check query efficiency and indexes

### Debugging Steps
1. **Check database file** exists and is accessible
2. **Verify Prisma client** is up to date
3. **Test database operations** in isolation
4. **Review error logs** for specific error messages
5. **Recreate database** if corruption suspected
