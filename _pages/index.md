## 🎯 About Lazy Perfectionist

> **🎸 Project Overview:** Lazy Perfectionist is an instrumental progressive rock/metal project created in a Hong Kong bedroom studio. I blend technical precision with emotional storytelling through orchestral layers, EDM-inspired synths, and anime music influences.

### 🛠️ Technology Stack
- **Framework**: Next.js 15 with TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Database**: SQLite with Prisma ORM
- **Deployment**: Vercel (recommended)
- **APIs**: Spotify, Medium integrations

### 🎵 Key Features
- **🎵 Music Integration**: Spotify API for track listings
- **📝 Blog Integration**: Medium API for blog posts
- **📱 Responsive Design**: Mobile-first approach
- **🔍 SEO Optimized**: Comprehensive SEO implementation
- **⚡ Performance**: Optimized loading and animations
- **🎨 Modern UI**: shadcn/ui with Framer Motion
